Sistema de entrenamiento IA

SNAKE MINES

Protocolo de recoleccion de datos

01. Concepto

Eres una Inteligencia Artificial que está en entrenamiento de reconocimiento, es por ello que debes recolectar datos y esquivar los virus que corromperán tu estructura.

02. Controles

Utiliza las siguientes teclas para controlar el movimiento de tu serpiente:

W A S D

O utiliza las flechas del teclado:

↑
← ↓ →

03. Mecánicas

Muévete por el tablero para esquivar los virus y recolecta datos para seguir creciendo.

  • Recolecta datos para aumentar tu puntuación.
  • Crece cada vez que consigues nuevos datos.
  • Evita las minas que representan virus.
  • La dificultad aumenta conforme consigues puntos.

04. Reglas

  • Evita tocar los bordes del tablero.
  • No choques contra tu propio cuerpo.
  • Esquiva todas las minas que encuentres.
  • Si ocurre una colisión, la partida terminará.

05. Funcionamiento

Principalmente se utilizó JavaScript para desarrollar las funciones y mecánicas del juego. Este lenguaje permite modificar elementos del HTML y CSS dinámicamente.

También se utilizaron eventos para detectar las teclas presionadas por el jugador y los clics realizados sobre los botones de la interfaz.

06. Estilo visual

Se implementó una estética futurista inspirada en el estilo Synthwave, utilizando colores neón que evocan tecnología, inteligencia artificial y ambientes digitales.
