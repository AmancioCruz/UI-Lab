01 / IDEA PRINCIPAL

Concepto

Transformaciones del cielo es una animación digital interactiva en 2D que representa diferentes momentos y fenómenos del cielo mediante elementos gráficos como el sol, la luna y las nubes. El usuario puede seleccionar entre cuatro escenarios: día, noche, eclipse y cielo nublado. Cada uno presenta cambios de iluminación, color y movimiento para crear una experiencia visual dinámica e interactiva.

02 / INTERACCIÓN

Controles y mecánicas

☀

Día

Muestra un cielo iluminado con el sol.

☾

Noche

Realiza una transición hacia un cielo oscuro y muestra la luna.

◐

Eclipse

Inicia una secuencia en la que la luna se desplaza frente al sol.

☁

Nublado

Presenta un cielo grisáceo con nubes en movimiento.

Mecánicas de animación

Las mecánicas principales consisten en transiciones de color e iluminación, movimientos y apariciones de elementos gráficos. El cielo cambia progresivamente de tonalidades claras a oscuras durante la transición del día a la noche. Durante el eclipse, la luna se desplaza horizontalmente frente al sol, mientras que en la escena nublada las nubes ingresan desde los extremos del escenario. Los elementos también utilizan transparencias, degradados y efectos de iluminación para dar mayor dinamismo a las escenas.

03 / DESARROLLO

Reglas y funcionamiento

Reglas de interacción

Al tratarse de una animación interactiva y no de un videojuego, no existen puntuaciones, vidas ni condiciones de victoria o derrota. El usuario puede seleccionar cualquiera de los cuatro botones para activar una secuencia específica. Una vez iniciada, la animación se reproduce automáticamente y puede cambiarse seleccionando otra opción. Todas las escenas se visualizan dentro del área de dibujo y no requieren acciones adicionales del usuario.

Funcionamiento

El proyecto funciona mediante HTML, CSS y JavaScript. HTML establece la estructura de la página, CSS define la apariencia de la interfaz y JavaScript controla las interacciones, realiza los dibujos y ejecuta las animaciones.

Los elementos gráficos se generan mediante Canvas 2D, utilizando figuras geométricas, degradados, transparencias y trazos. Para producir los movimientos y transiciones se utiliza requestAnimationFrame(), que permite actualizar continuamente los dibujos y conseguir animaciones fluidas.

04 / IDENTIDAD GRÁFICA

Estilo visual y assets

El proyecto utiliza un estilo de ilustración digital 2D muy similar al vectorial, con formas geométricas, degradados y transparencias. Se busca una apariencia limpia y sencilla, en la que los elementos principales tengan protagonismo. La interfaz utiliza una paleta de colores compuesta por tonos morados, verdes lima y azules.
